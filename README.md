# WeCARE - Healthcare Management System


WeCARE is a healthcare management project developed using Java and Spring Boot. The main purpose of this project is to make healthcare-related activities easier to manage.

This project mainly focuses on managing appointments and handling healthcare information through REST APIs. It also uses database connectivity to store and retrieve the required data.

## Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL / H2 Database
- Maven
- IntelliJ IDEA
- Postman

## Modules

- Appointment Management
- REST API
- Database Management
- Exception Handling

## Features

- Add new appointments
- View appointment details
- Retrieve appointment records
- Handle appointment-related requests
- Store appointment information in the database

## Tools Used

- IntelliJ IDEA – Used for developing the application.
- Postman – Used for testing API requests.
- MySQL / H2 – Used for storing application data.
- GitHub – Used to upload and maintain the project.

## Project Purpose

This project helped me understand how to develop REST APIs using Spring Boot, connect an application with a database, and perform operations using Spring Data JPA.
